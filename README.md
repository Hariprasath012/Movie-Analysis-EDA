# Movie Analysis — Exploratory Data Analysis

## Project Overview
This project explores movie ratings, budgets, and worldwide box-office performance using Python. It demonstrates the fundamentals of Exploratory Data Analysis (EDA).

**Note:** The dataset contains illustrative practice values for learning purposes. The figures are not verified real-world movie statistics.

## Objectives
- Explore movie data using Pandas.
- Check missing values, duplicates, and data quality.
- Analyze ratings, budgets, and box-office performance.
- Explore correlations and potential outliers.
- Communicate findings through charts and a final report.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- Excel

## Project Files
- `Movie_Analysis.ipynb` — notebook containing the analysis code.
- `Movie_Analysis_Final.xlsx` — exported analysis dataset.
- `Movie_Analysis_Dashboard (1).png` — dashboard screenshot.
- `Movie_Analysis_Final_Report.md` — final written report.

## Analysis Performed
1. Inspected the dataset and calculated summary statistics.
2. Checked missing values and duplicate records.
3. Explored movie genres and descriptive statistics.
4. Examined budget, box-office revenue, and ratings.
5. Used correlation analysis and outlier exploration.
6. Created visualizations, including bar charts, a histogram, a scatter plot, and a box plot.

## Key Learning Outcomes
- Practiced data inspection and cleaning checks.
- Learned to group and summarize data using Pandas.
- Practiced visualizing patterns in data.
- Learned that correlation does not establish causation.
- Communicated findings in a structured report.

## Conclusion
This beginner project demonstrates an end-to-end EDA workflow, from inspecting a dataset to creating visualizations and reporting findings.
